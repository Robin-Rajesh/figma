# 🍔 QuickBite Mobile UI Prototype

A mobile food-ordering UI prototype designed in Figma and exported as a React + TypeScript project using Vite and Radix UI components.

🎨 **Design file:** [QuickBite Mobile UI Prototype on Figma](https://www.figma.com/design/fJo1j3hdESziksY6pUk9Xo/QuickBite-Mobile-UI-Prototype)

## 🚀 Running the code

```bash
npm i
npm run dev
```

> **Note:** this repository currently contains the project configuration (`package.json`, `vite.config.ts`, `index.html`) but not the `src/` folder with the components. Add the exported `src/` folder from Figma to run the prototype.
